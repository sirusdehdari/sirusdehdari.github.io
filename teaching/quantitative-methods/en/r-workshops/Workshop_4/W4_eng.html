Read today’s data

We use the voter survey again. The question we practise on is whether watching TV is associated with having taken part in a demonstration (demonstrated, 1 = yes).

Download survey.csv

survey <- read.csv("survey.csv")
mean(survey$demonstrated)
mean(survey$tv_hours)

32 percent of the respondents have taken part in a demonstration, and on average they watch just over 8 hours of TV a week.

Reversing a scale

interest measures political interest from 1 = very interested to 5 = not at all interested. It is more intuitive if a high value means more interest. On a scale from 1 to 5, you reverse the order with 6 minus the value:

survey$interest_re <- 6 - survey$interest

Then 1 becomes 5, 2 becomes 4, 3 stays 3, 4 becomes 2 and 5 becomes 1. For a scale from 1 to k, the general recipe is (k + 1) - x.

Checking the recoding

Always make a cross-table of the old and the new variable:

table(survey$interest, survey$interest_re)

The rows are the old variable and the columns the new one. All observations should lie on a diagonal: old 1 against new 5, old 2 against new 4, and so on. If the variable had had missing values, they would have stayed NA, since 6 minus NA is NA.

When the dependent variable is 0 or 1

m1 <- lm(demonstrated ~ tv_hours, data = survey)
summary(m1)

When y can only be 0 or 1, a linear regression is called a linear probability model. The coefficient is read as a change in the probability that y is 1.

Here the coefficient for tv_hours is about 0.030: one more hour of TV a week is associated with a 3 percentage points higher probability of having demonstrated.

Small coefficients

In a linear probability model the coefficients are often small, since they measure changes in a probability between 0 and 1. summary() rounds, so use coef() when you need more decimals:

coef(m1)
coef(m1)[["tv_hours"]]
round(coef(m1)[["tv_hours"]], 4)

Round only when you write the answer, not in the intermediate steps. Multiply by 100 to get the change in percentage points.

Multiple regression

You add more independent variables with +:

m2 <- lm(demonstrated ~ tv_hours + interest_re, data = survey)
summary(m2)

The coefficient for tv_hours in m2 is the association between watching TV and taking part in demonstrations when political interest is held constant. The comparison is thus made between people with the same interest. The coefficient for interest_re is interpreted in the same way, with TV watching held constant.

Comparing the coefficient across models

What is interesting is often how the coefficient of the main variable changes when a control variable is added:

coef(m1)[["tv_hours"]]
coef(m2)[["tv_hours"]]

The coefficient falls from 0.030 to 0.019 when political interest is held constant. Part of the bivariate association was thus due to the fact that people with more political interest, in these fictional data, both watch more TV and demonstrate more often.

What role does the control variable have?

  • If the control variable affects both x and y, it is a confounder. Part of the bivariate association was then bias, and the coefficient changes when you control for it.
  • If the control variable is itself affected by x and then affects y, it is a mediator. Controlling for it then removes part of the real effect of x.
  • If the variable affects y but is not related to x, the coefficient for x barely changes. The estimate can, however, become more precise, with a smaller standard error.
  • Which role a variable has is decided by theory and knowledge of the subject, not by R.

A table with several models

Put the models in the order you want to compare them: the bivariate model first, then with one control, then with another.

m3 <- lm(demonstrated ~ tv_hours + interest_re + female, data = survey)
library(stargazer)
stargazer(m1, m2, m3, type = "text")

Read the table row by row: the row for tv_hours shows the coefficient in each model side by side. The coefficient is almost the same in m2 and m3, so sex barely changes the association. At the bottom are the number of observations and R² for each model.

Readable names in the table

Variable names such as interest_re are hard for others to read. Give the variables and the dependent variable readable names when you save the table:

stargazer(m1, m2, m3, type = "html", out = "models.html",
          covariate.labels = c("TV watching (hours/week)",
                               "Political interest", "Woman"),
          dep.var.labels = "Has demonstrated")

The names in covariate.labels must be in the same order as the variables in the table. In the assignment, choose Add when it asks whether the file should be added to your submission. In your own work, open the HTML file in a web browser and copy the table into Word.

A script from start to finish

A good script can be run from top to bottom and gives the same results every time:

# 1. Data
survey <- read.csv("survey.csv")
# 2. Recoding
survey$interest_re <- 6 - survey$interest
table(survey$interest, survey$interest_re)
# 3. Models
m1 <- lm(demonstrated ~ tv_hours, data = survey)
m2 <- lm(demonstrated ~ tv_hours + interest_re, data = survey)
m3 <- lm(demonstrated ~ tv_hours + interest_re + female, data = survey)
# 4. Table
library(stargazer)
stargazer(m1, m2, m3, type = "html", out = "models.html")
