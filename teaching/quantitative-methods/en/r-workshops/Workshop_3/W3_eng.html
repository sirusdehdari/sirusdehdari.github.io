Read today’s data

Today we use a fictional dataset with 250 municipalities. For each municipality there is the population, the number of young people, the number of unemployed and the voter turnout in percent.

Download municipalities.csv

muni <- read.csv("municipalities.csv")
head(muni)
summary(muni)

We call the dataset muni, short for municipalities. Each row is a municipality. population, young and unemployed are numbers of people, and turnout is the share who voted, in percent.

Two datasets in the same task

In assignment 2 there are two datasets in the same task. Give them different names, for example data1 and data2, and always write out which dataset you use:

mean(data2$turnout)
lm(turnout ~ share_young, data = data2)

A common mistake is to calculate on the wrong dataset, for example to estimate the model on data1 when the question is about data2. R does not object as long as the variables exist in both datasets, so check the name in every line.

Shares in percent from counts

Counts say little when the municipalities differ in size: 2,000 unemployed people are many in a small municipality but few in a large one. So convert the counts into shares in percent of the population:

muni$share_young      <- 100 * muni$young / muni$population
muni$share_unemployed <- 100 * muni$unemployed / muni$population
summary(muni$share_young)

The calculation is done for each municipality. The share of young people varies from just over 10 to just under 30 percent.

Selecting several columns

For a table of several variables, first select the columns. Inside the square brackets the rows come first and the columns second, and nothing before the comma means all rows:

vars <- muni[, c("turnout", "share_young", "share_unemployed")]
head(vars)

vars is a new dataset with the same 250 municipalities but only the three variables.

The same function on every column

sapply() runs the same function on every column and collects the answers:

sapply(vars, mean)
sapply(vars, sd)       # the standard deviation
sapply(vars, median)

The answer has one value per variable, with the variable’s name above it. It is the same as writing mean(vars$turnout), mean(vars$share_young) and so on, but on one line.

A small function of your own

The range is the largest value minus the smallest. No ready-made function gives it as a single number, but you can write your own function directly in the call:

sapply(vars, function(x) max(x) - min(x))

function(x) max(x) - min(x) means: take a variable, call it x, and return the largest minus the smallest value. sapply() gives the function one column at a time. The function range() exists, but it gives two numbers, the smallest and the largest, and not the difference between them.

Building a table

Put the measures together into a table with data.frame(). Each argument becomes a column, and the rows get the variables’ names:

desc <- data.frame(
  mean  = sapply(vars, mean),
  sd    = sapply(vars, sd),
  range = sapply(vars, function(x) max(x) - min(x))
)
round(desc, 2)

You get a single cell with the row and column names: desc["share_young", "mean"] gives the mean of the share of young people.

Saving the table

Save the table with stargazer, just as in workshop 2:

library(stargazer)
stargazer(round(desc, 2), type = "html", summary = FALSE,
          out = "descriptive.html")

The file ends up in the working directory and appears under Files. In the assignment, choose Add when it asks whether the file should be added to your submission. In your own work, open the HTML file in a web browser and copy the table into Word.

Scatter plot

A scatter plot shows the relationship between two variables, with one point per observation:

plot(turnout ~ share_unemployed, data = muni)

y ~ x is read “y against x”: the dependent variable is to the left of the tilde ~ and ends up on the vertical axis. Each point is a municipality. The plot appears under Plots, both in RStudio and in the panel here.

Regression line and axis titles

abline() draws a line in the latest plot. If you give it a regression model, it draws the estimated regression line:

plot(turnout ~ share_unemployed, data = muni,
     xlab = "Unemployed (%)", ylab = "Turnout (%)")
abline(lm(turnout ~ share_unemployed, data = muni))

xlab and ylab give the axes readable titles. The line slopes downwards: municipalities with a larger share of unemployed have lower turnout on average.

Saving the plot as an image

To save a plot, first open an image file, then draw, and finally close the file:

png("plot_unemployment.png")
plot(turnout ~ share_unemployed, data = muni)
abline(lm(turnout ~ share_unemployed, data = muni))
dev.off()

While the image file is open, nothing appears under Plots, since everything is drawn into the file. Do not forget dev.off(): only then is the image finished. The file then appears under Files, and in the assignment you can add it to your submission.

Bivariate regression

lm() estimates a linear regression. The dependent variable goes to the left of ~ and the independent variable to the right:

m1 <- lm(turnout ~ share_unemployed, data = muni)
summary(m1)

The model is saved as the object m1, and summary() shows the results. The next slide goes through the most important parts of the output.

Reading the output

  • Estimate for share_unemployed is the slope coefficient: how much turnout changes on average when the share of unemployed increases by one percentage point. Here it is −0.52.
  • (Intercept) is the estimated turnout when the share of unemployed is 0.
  • Std. Error is the standard error, the uncertainty of the estimate.
  • t value and Pr(>|t|) are the t-value and the p-value for the null hypothesis that the coefficient is 0. A p-value below 0.05 means that the relationship is statistically significant at the 5 percent level.
  • Multiple R-squared is R²: the share of the variation in turnout that the model explains, here 0.23.

Interpreting the coefficient in words

A coefficient is interpreted in the units of the variables. Both turnout and the share of unemployed are measured in percent, so the coefficient −0.52 means:

A municipality where the share of unemployed is one percentage point higher has, on average, 0.52 percentage points lower turnout.

This is an association and not necessarily an effect. Municipalities with many unemployed people may differ from other municipalities in many other ways that also affect turnout. How to control for such differences is the topic of workshop 4.

Single values from the model

You often need a single number from the model, for example to write it in your text:

coef(m1)                          # all coefficients
coef(m1)[["share_unemployed"]]    # only the slope
summary(m1)$r.squared             # R²
nobs(m1)                          # number of observations in the model

nobs() matters when the data have missing values: lm() skips rows where any of the model’s variables is missing, so the model can have fewer observations than the dataset.

Regression table

stargazer makes a regression table with one column per model:

m2 <- lm(turnout ~ share_young, data = muni)
stargazer(m1, m2, type = "text")
stargazer(m1, m2, type = "html", out = "regressions.html")

With type = "text" you see the table directly in the console, and with type = "html" and out you save it as a file. The table shows the coefficients with standard errors in parentheses, stars for significance, and the number of observations and R² for each model.
